# WeSplit 💸

A simple bill-splitting and tip calculator app built with **SwiftUI**.

## ✨ Features

- 💵 **Bill Splitting**: Easily divide the bill among 2 to 10+ people.
- 🏷️ **Tip Selection**: Quick segmented picker for tips (0%, 5%, 10%, 15%, 20%).
- 🌍 **Local Currency**: Automatically formats to your region's currency.
- ⌨️ **Smooth UX**: Numeric decimal keypad with a "Done" button to dismiss.

## 🛠️ Requirements

- iOS 16.0+
- Xcode 15.0+
- Swift 5.0+

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Prathmesh-04/WeSplit.git
   ```
2. Open `WeSplit.xcodeproj` in Xcode.
3. Press **Cmd + R** to build and run on a simulator or device.
